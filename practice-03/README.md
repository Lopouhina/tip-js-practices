## Организация кода

- `data.js` — хранение исходных наборов задач.
- `task-service.js` — поиск, изменение статуса, удаление задач
  и вычисление статистики.
- `task-selectors.js` — отбор задач по выбранному фильтру.
- `task-view.js` — создание карточек, отображение списка,
  статистики и сообщений о пустом состоянии.
- `main.js` — управление состоянием приложения,
  обработка событий и обновление интерфейса.

Полный список задач хранится в переменной `currentTasks`,
а текущий фильтр — в переменной `currentFilter`.

Обработчики событий назначаются контейнерам списка и фильтров
один раз. Для определения нажатой кнопки используется
метод `closest()`.

Сводка вычисляется функцией `getTaskStats()` по полному
массиву задач, независимо от выбранного фильтра.

Функция `renderApp()` отвечает за обновление интерфейса.

## Отладка и клавиатура

Для отладки используется вкладка Sources
в инструментах разработчика браузера.

Точка останова устанавливается в файле `main.js`
на строке:

```javascript
const id = Number(rawId);
```

При отладке проверяются следующие значения:

- `event.target` — элемент, на который нажал пользователь;
- `event.currentTarget` — контейнер списка задач;
- `rawId` — строковый идентификатор карточки;
- `id` — идентификатор после преобразования в число;
- `action` — выполняемое действие toggle или delete;
- `result` — результат выполнения функции сервиса.

Для клавиатурного управления используются клавиши
Tab, Enter и Space.

Функция `restoreTaskFocus()` восстанавливает фокус
после перерисовки списка. Если карточка больше не
отображается, фокус переносится на активный фильтр.

Предусмотрена обработка некорректных идентификаторов:

| Идентификатор | Ожидаемое поведение |
|---|---|
| 777 | Сообщение «Задача не найдена» |
| 4abc | Сообщение «Некорректный идентификатор задачи» |

При ошибке состояние приложения не изменяется.

Фактические значения отладчика и результаты клавиатурных
проверок необходимо зафиксировать после выполнения.

## Вывод

В ходе практической работы изучены принципы работы с DOM,
создание HTML-элементов средствами JavaScript,
обработка и делегирование событий.

состояния приложения.

повторного назначения обработчиков при перерисовке списка.
